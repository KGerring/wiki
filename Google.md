# 🧭 Google Search Operators Reference Guide
A complete and categorized list of Google’s advanced search operators for precision querying, research, and data discovery.

## 🔍 Basic Search Operators
| Operator | Example | Function |
|-----------|----------|----------|
| `" "` | `"quantum computing"` | Search for an **exact phrase** only. |
| `OR` | `AI OR "machine learning"` | Search for **either** term. |
| `-` | `-facebook` | **Exclude** a word or domain. |
| `*` | `"the * of AI"` | Acts as a **wildcard** for any term. |
| `()` | `(AI OR "machine learning") ethics` | Group terms for **logical** operations. |

## 🌐 Site & Domain Filters
| Operator | Example | Function |
|-----------|----------|----------|
| `site:` | `site:harvard.edu` | Limit results to a **specific domain**. |
| `inurl:` | `inurl:climate` | Search for terms within the **URL**. |
| `allinurl:` | `allinurl:research AI` | URL must contain **all specified terms**. |
| `intitle:` | `intitle:"climate change"` | Search for terms in the **page title**. |
| `allintitle:` | `allintitle:AI ethics` | All words must appear in the **title**. |
| `intext:` | `intext:"sustainable energy"` | Search within the **body text**. |
| `related:` | `related:nature.com` | Find **websites similar** to the one specified. |

## 📄 File Type & Document Searches
| Operator | Example | Function |
|-----------|----------|----------|
| `filetype:` | `filetype:pdf climate report` | Search for **specific file formats** (PDF, DOCX, PPTX, etc.). |
| `ext:` | `ext:csv` | Alternate form of `filetype:`. |

## 🕰️ Date & Range Searches
| Operator | Example | Function |
|-----------|----------|----------|
| `before:` | `AI before:2022` | Results **before** a certain date. |
| `after:` | `AI after:2023` | Results **after** a certain date. |
| `..` | `2015..2020` | Search within a **numeric range** (dates, prices, years, etc.). |

## 📍 Content-Specific Searches
| Operator | Example | Function |
|-----------|----------|----------|
| `define:` | `define:epigenetics` | Retrieve a **dictionary definition**. |
| `source:` | `source:nature` | Restrict results to a **specific publication** (Google News only). |
| `location:` | `AI policy location:Germany` | Filter results by **region or country**. |
| `map:` | `map:coffee shops near Stanford` | Display results from **Google Maps**. |

## 🧠 Advanced & Rarely Known Operators
| Operator | Example | Function |
|-----------|----------|----------|
| `cache:` | `cache:nytimes.com` | View Google’s **cached version** of a page. |
| `info:` | `info:ox.ac.uk` | Display **basic information** about a website. |
| `AROUND(X)` | `"quantum" AROUND(3) "computing"` | Finds terms **within X words** of each other. |
| `inanchor:` | `inanchor:"climate policy"` | Search for **anchor text** in hyperlinks. |
| `allinanchor:` | `allinanchor:AI ethics` | Require all words in **anchor text**. |
